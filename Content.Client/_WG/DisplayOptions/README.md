# DisplayOptions

Options controls for display settings that already existed as cvars but had no control in Game Options. Graphics:
a frame rate cap (`display.max_fps`) under Display, "Show the space background" (`parallax.enabled`), and the
light bloom toggle, bloom strength and film grain from the SCP layer (`scp.light_bloom_enable`,
`scp.light_bloom_strength`, `shader.grain_toggle_overlay`) under Quality. Misc: "Outline what's under the cursor"
(`outline.enabled`) under Cursor.

`outline.enabled` and `parallax.enabled` weren't saved between launches, so marked edits add `CVar.ARCHIVE` to them. The
`toggleoutline` command now persists too.

Entry points: `GraphicsTab.WgAddDisplayOptions`, called from the `GraphicsTab` constructor, and a marked line in
`MiscTab` for the outline checkbox.
