# CombatFacing

A Misc tab option, **Face the cursor in combat mode** (`wf.combat_face_cursor`, on by default). On, combat mode turns
you toward the mouse as before. Off, combat mode leaves facing alone and you turn by moving.

The cvar is a replicated client cvar, so the server reads each player's choice when they enter combat mode, through
`WFCombatFacingSystem.WantsFaceCursor` from a marked edit in `SharedCombatModeSystem.SetInCombatMode`. Mobs with no
player keep facing the cursor. Flipping the option mid-fight sends `WFCombatFaceCursorChangedEvent`, and the server
adds or removes the mouse rotator then and there, so a stale `NoRotateOnMoveComponent` never stops you turning.
