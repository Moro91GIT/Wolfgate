# DarkFlash

A photosensitivity option: Game Options > Accessibility > "Darken bright flashes" (`wf.dark_flash`, off by default).
SS14's flash already fades in from black, so the option covers what is still bright or moving:

- the warhead flash (`WFNuclearFlashOverlay`) goes black instead of white;
- being flashed uses `WFFlashedEffectStill`, a plain fade without the two spinning after-images.

Entry points: `FlashOverlay.WfFlashShader`, which a marked edit in `FlashOverlay.Draw` uses in place of the fixed
shader, and the colour choice in `WFNuclearFlashOverlay`.
