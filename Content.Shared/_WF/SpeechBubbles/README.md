# SpeechBubbles

The player's own speech bubble settings, under Game Options > Misc > Speech. All are on by default, matching the old
behaviour:

- show speech bubbles at all (`wf.speech_bubbles`);
- from objects that aren't mobs, such as radios and vending machines (`wf.speech_bubbles_non_mobs`);
- dead chat as bubbles while a ghost (`wf.speech_bubbles_ghosts`);
- emotes as bubbles (`wf.speech_bubbles_emotes`).

A length slider (`wf.speech_bubble_max_length`, 0 for the whole message, at least 20 otherwise) cuts long bubbles with
an ellipsis. LOOC bubbles keep their existing toggle.

Entry points: `ChatUIController.WfShowSpeechBubble`, called from `AddSpeechBubble` by a marked edit, and
`WFBubbleLength.Truncate`, called from `SpeechBubble.FormatSpeech`. It cuts the parsed message's text nodes and closes
any tags left open, so the markup stays valid.
